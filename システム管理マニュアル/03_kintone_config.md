# 第3章 Kintone接続設定

Kintoneとの接続に必要なアプリID・APIトークンと、質問機能（操作マニュアルへの質問）の設定手順です。

---

## 3-1. 設定の保存場所

| 設定 | 保存場所 | 設定方法 |
|---------|------|------|
| KintoneアプリID（`kintone_app_ids.json`） | インストールフォルダの `Config\`（優先）、なければ `%LOCALAPPDATA%\AccountReconciler\` | ファイル（→ 3-2） |
| APIトークン | `%LOCALAPPDATA%\AccountReconciler\kintone_api_tokens.dat`（暗号化） | メンテナンス画面で `kintone_api_tokens.json` を取り込む（→ 3-3） |
| 質問機能の設定 | `%LOCALAPPDATA%\AccountReconciler\manual_chat.dat`（暗号化） | APIトークンと同じファイルに書いて取り込む（→ 3-4） |

---

## 3-2. KintoneアプリIDの確認と設定

### アプリIDの確認方法

KintoneでアプリIDを確認するには、対象アプリをブラウザで開き、URLを確認します。

```
https://（ドメイン）.cybozu.com/k/（アプリID）/
                                    ↑ここがアプリID
例：https://yourcompany.cybozu.com/k/46/  → アプリID は 46
```

### 設定ファイルの編集

アプリIDは、インストールフォルダの `Config\kintone_app_ids.json` が優先して使われます（インストール時の値）。Kintoneのアプリ構成を変えた場合など、IDを変える必要があるときは担当開発者に連絡してください。インストールフォルダの `Config\` にファイルがない場合は、`%LOCALAPPDATA%\AccountReconciler\kintone_app_ids.json` が使われます。

ファイルの形式は以下のとおりです。

```json
{
  "buildingAppId": 34,
  "buildingTypeAppId": 35,
  "propertyAppId": 40,
  "memberPropertyOwnershipAppId": 44,
  "memberParkingContractAppId": 43,
  "memberAppId": 96,
  "billingAppId": 46
}
```

| キー | 対応するKintoneアプリ |
|------|---------------------|
| `buildingAppId` | M_棟 |
| `buildingTypeAppId` | M_棟タイプ |
| `propertyAppId` | M_物件 |
| `memberPropertyOwnershipAppId` | M_組合員物件所有状況 |
| `memberParkingContractAppId` | M_組合員駐車場契約 |
| `memberAppId` | M_組合員 |
| `billingAppId` | M_請求レコード |

---

## 3-3. APIトークンの発行と設定

### APIトークンの発行手順（Kintone側）

各アプリに対して個別にトークンを発行します。以下の手順を7アプリ分繰り返します。

1. Kintoneで対象アプリを開きます
2. 右上の **「アプリの設定」** （歯車アイコン）をクリックします
3. **「APIトークン」** をクリックします
4. **「生成する」** をクリックして新しいトークンを発行します
5. 必要なアクセス権限を設定します（下表参照）
6. **「保存」** をクリックし、**「アプリを更新」** をクリックして確定します

### 各アプリに必要なアクセス権限

| アプリ | 必要な権限 |
|--------|----------|
| M_棟 | レコード閲覧 |
| M_棟タイプ | レコード閲覧 |
| M_物件 | レコード閲覧 |
| M_組合員物件所有状況 | レコード閲覧 |
| M_組合員駐車場契約 | レコード閲覧 |
| M_組合員 | レコード閲覧 |
| M_請求レコード | レコード閲覧・追加・編集 |

### APIトークンの取り込み（アプリ側）

発行したトークンを書いた `kintone_api_tokens.json` を作り、アプリのメンテナンス画面から取り込みます。
取り込んだトークンは、このPC・このWindowsユーザー専用に暗号化して保存されます。

1. テキストエディタで `kintone_api_tokens.json` という名前のファイルを作り、発行したトークンを書きます（7アプリ分すべて必要です）

```json
{
  "buildingApiToken": "（M_棟のトークン）",
  "buildingTypeApiToken": "（M_棟タイプのトークン）",
  "propertyApiToken": "（M_物件のトークン）",
  "memberPropertyOwnershipApiToken": "（M_組合員物件所有状況のトークン）",
  "memberParkingContractApiToken": "（M_組合員駐車場契約のトークン）",
  "memberApiToken": "（M_組合員のトークン）",
  "billingApiToken": "（M_請求レコードのトークン）"
}
```

2. アプリにログインし、左側メニューから **「メンテナンス」** を開きます
3. **「APIトークン」** セクションの **「ファイルから取り込む」** をクリックします
4. 作成した `kintone_api_tokens.json` を選択します
5. 「APIトークンを取り込み、暗号化して保存しました。選択した元のファイルは削除してください。」と表示されたら、取り込み完了です
6. 「状態:」が **「設定済み」** になったことを確認します
7. **選択した元のファイル（`kintone_api_tokens.json`）を削除します**

| 「状態:」の表示 | 意味 |
|---------|------|
| 設定済み | 7アプリ分のトークンが取り込まれている |
| 一部未設定（アプリ名） | 表示されたアプリのトークンがない。トークンをそろえて取り込み直す |
| 未設定 | トークンが取り込まれていない |
| 読み込みエラー（取り込み直してください） | 保存したトークンを読めない（別のPC・ユーザーからコピーした場合など）。取り込み直す |

> **取り込めない場合**
> - 「次のアプリのAPIトークンが設定されていません: …」：表示されたアプリのトークンが空です。7アプリ分すべて書いてから取り込んでください
> - 「APIトークンのファイルを読み込めませんでした」「APIトークンが書かれていません」：ファイルの形式（JSON）やキーの名前を確認してください

> **セキュリティ上の注意**
> - `kintone_api_tokens.json` は第三者に見せないでください。取り込んだあとは削除してください
> - git リポジトリにコミットしないでください（`.gitignore` に登録済み）
> - 取り込んだトークンは暗号化されているため、別のPC・別のWindowsユーザーにファイルをコピーしても使えません。PCごとに取り込んでください

> 以前の手順で `%LOCALAPPDATA%\AccountReconciler\kintone_api_tokens.json` を直接置いていた場合は、アプリが読み込んで暗号化形式に移し、平文のファイルを削除します。

## 3-4. 質問機能の設定

アプリの「質問する」（操作マニュアルへの質問。→ [運用マニュアル 第1章 1-8](../運用マニュアル/01_overview.md#1-8-操作方法を質問する)）を使うには、質問機能の接続先（URL）とアプリ用トークンを取り込みます。
アプリ用トークンは、質問機能のサービス（チャットボット）の管理者から受け取ります。全PC共通の秘密情報です。

1. `kintone_api_tokens.json` に、`manualChatUrl` と `manualChatToken` を書き足します（質問機能の設定だけを書いたファイルでも取り込めます）

```json
{
  "buildingApiToken": "（M_棟のトークン）",
  "...": "（ほかのアプリのトークン）",
  "manualChatUrl": "https://（質問機能のサービスのURL）",
  "manualChatToken": "（アプリ用トークン）"
}
```

2. メンテナンス画面の **「APIトークン」** セクションの **「ファイルから取り込む」** で、このファイルを選択します
3. 「質問機能:」が **「設定済み」** になったことを確認します
4. 選択した元のファイルを削除します

| 項目 | 決まり |
|------|------|
| `manualChatUrl` | `https://` から始まるURL |
| `manualChatToken` | 半角の英数字と記号だけ（日本語・全角の文字・空白は使えません） |

- `manualChatUrl` と `manualChatToken` は両方書いてください。片方だけでは取り込めません
- 「質問機能:」が「未設定（質問機能は使えません）」のときは、利用者の画面に「このPCには質問機能の設定がありません」と表示されます
- 利用者の画面に「質問機能の設定を確かめてください」と表示される場合は、トークンが質問機能のサービス側と合っていません。正しいトークンで取り込み直してください
- 1日に質問できる回数の上限（PCごと・全体）は、質問機能のサービス側で設定します

---

## 3-5. 設定後の動作確認

1. アプリを起動してKintoneのログインIDでログインします
2. ダッシュボードが正常に表示されることを確認します
3. メンテナンス画面の「APIトークン」の「状態:」が「設定済み」であることを確認します
4. 左側メニューから **「締め処理」** を開き、**「請求データ生成」** をクリックします
5. データが取得されれば接続設定は正常です
6. 質問機能を設定した場合は、画面上部の「質問する」をクリックし、「今日はあと N 回質問できます」と表示されることを確認します

エラーが表示される場合は [第8章 トラブルシューティング](08_troubleshooting.md) を参照してください。

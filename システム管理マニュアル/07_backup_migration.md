# 第7章 バックアップ・PC移行

---

## 7-1. バックアップの重要性

このシステムのデータは以下の2つで構成されています。

| データ | 場所 | 説明 |
|--------|------|------|
| データベース | アプリ専用フォルダの `SecureBank.db`（メンテナンス画面の「DBファイル情報」に表示） | 口座情報・処理履歴・マスタデータ |
| 暗号化キー | `%APPDATA%\AccountReconciler\secret.key` | 口座情報の復号に必要 |

**この2つはセットで管理する必要があります。**
データベースだけ、またはキーだけを個別にコピーしても、別のPC・環境では口座情報を復号できません。

アプリのバックアップ機能はこの2つをZIPにまとめて保存・復元します。

> **アプリをアンインストールすると、データベースと暗号化キーは削除されます。**
> アンインストールやPC移行の前には、必ず手動バックアップ（「バックアップ作成」）を作成してください。

### 自動バックアップと手動バックアップ

| | 自動バックアップ | 手動バックアップ |
|---|---|---|
| 作成のタイミング | アプリ起動時、前回のバックアップから28日以上たっている場合 | メンテナンス画面の「バックアップ作成」 |
| 保存先 | ドキュメントフォルダの `UnionDuesCollectionManager\AutoBackup`（`backup_auto_YYYY-MM-DD.zip`） | 保存ダイアログで選んだ場所 |
| 保存期間 | 1年より古いものは自動で削除 | 削除されない |
| 復元できるPC | 作成したPC・Windowsユーザーのみ（暗号化キーをDPAPIで保護したまま格納） | どのPCでも復元できる（PC移行用） |

メンテナンス画面の「バックアップ」セクションで、「最後のバックアップ」の日時と「自動バックアップ先」を確認できます。「自動バックアップのフォルダを開く」で保存先を開けます。

## 7-2. バックアップ手順

### 実施タイミング（推奨）

- **毎月の締め処理前**（最重要）
- PC交換・OSアップデートの前
- 大量のマスタデータを変更した後

### 手順

1. アプリを起動し、左側メニューから **「メンテナンス」** を開きます
2. **「バックアップ」** セクションの **「バックアップ作成」** ボタンをクリックします
3. 保存先フォルダを選択します
4. **「保存」** をクリックします
5. 「バックアップを作成しました: （保存先）」と表示されたら完了です

バックアップファイルはZIP形式で保存されます。

```
ファイル名例：UnionDuesCollectionManager_backup_20250301_1430.zip
```

### バックアップZIPの内容

| ファイル | 説明 |
|---------|------|
| `SecureBank.db` | データベース本体 |
| `encryption_key.bin` | 暗号化キー（DPAPIの保護を外した状態で格納）。自動バックアップでは代わりに `encryption_key.dpapi`（DPAPIで保護したまま）が入ります |

> **バックアップZIPには暗号化キーが平文で含まれます。**
> 第三者に渡さないよう、安全な場所（外付けドライブ、パスワード保護ストレージなど）に保管してください。

### 保管場所の推奨

- 外付けHDD・USBメモリ（PCと別管理）
- 組合で管理しているクラウドストレージ（アクセス制限付き）
- 複数世代（最低3世代）のバックアップを保持する

## 7-3. PC載せ替え手順

PCを新しくする際の完全な手順です。

```
【旧PC】
1. バックアップを取得する（↑7-2参照）
2. バックアップZIPを外付けメディア等にコピーする

【新PC】
3. システムをインストールする（→第2章）
4. Kintoneドメインの設定・ログイン・APIトークンの取り込みを行う（→第2章・第3章）
   ※ 取り込んだAPIトークン・質問機能の設定・GitHub PATはPCごとに暗号化されているため、バックアップには含まれません。新PCで取り込み直します
5. バックアップZIPをリストアする（↓7-4参照）
6. 動作確認する
```

> **「DBファイルをそのままコピーする」方法は絶対に使用しないでください。**
> 暗号化キーはWindowsのユーザーアカウント情報と結合されているため、別PCにDBを直接コピーしても口座情報を復号できません。

## 7-4. リストア手順

バックアップZIPからデータを復元します。

### 実施前の確認

- 新PCにアプリがインストールされていること
- バックアップZIPファイルがアクセスできる場所にあること

### 手順

1. アプリを起動し、左側メニューから **「メンテナンス」** を開きます
2. **「リストア」** セクションの **「バックアップから復元」** ボタンをクリックします
3. ファイル選択ダイアログで、バックアップZIPを選択します
4. **「開く」** をクリックします
5. 「DBのリストア確認」ダイアログが表示されます。内容を確認して **「リストア実行」** をクリックします
6. 「リストア完了」ダイアログが表示され、**アプリが終了します**
7. アプリをもう一度起動します

### リストア後の処理（自動）

リストア時に以下が自動実行されます。

1. バックアップZIPからDBファイルを一時ファイルに展開し、バックアップの暗号化キーで口座情報を復号できることを確認
2. 現在のDBと暗号化キーを退避（途中で失敗した場合は元に戻す）
3. 暗号化キーを**新PCのDPAPI**で再保護（新PCのユーザーアカウントに紐付け直し）し、DBファイルを所定の場所に配置
4. アプリの次回起動時にDBマイグレーションを自動適用

### 動作確認

再起動後、以下を確認します。

- [ ] ダッシュボードが正常に表示される
- [ ] 「組合員口座マスタ」を開き、登録済みの口座情報が表示される（口座番号がマスクされた状態で表示されれば復号成功）
- [ ] 「締め処理履歴」で過去の処理ログが表示される

## 7-5. バックアップなしでの復旧（最終手段）

バックアップZIPが存在しない状態でDBや暗号化キーが失われた場合の対応です。

| 状況 | 対処 |
|------|------|
| DBのみ消失（暗号化キーは残存） | バックアップなし → マスタデータの再登録が必要 |
| 暗号化キーのみ消失（DBは残存） | 口座情報の復号不可 → 口座情報の再登録が必要 |
| 両方消失 | 全データの再登録が必要 |

いずれの場合も、銀行マスタ・委託先口座・組合員口座を再登録する必要があります。
処理ログ（締め処理・消込履歴）は復元できません。

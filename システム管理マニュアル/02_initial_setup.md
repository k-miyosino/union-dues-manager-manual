# 第2章 インストール・初期セットアップ

---

## 2-1. 動作要件

| 項目 | 要件 |
|------|------|
| OS | Windows 10 バージョン 19041（2020年5月更新）以降 |
| アーキテクチャ | x64（推奨）、x86、ARM64 |
| .NET ランタイム | .NET 10.0（インストーラーに同梱、または別途インストール） |
| インターネット接続 | Kintone APIへのアクセスに必要（HTTPS） |
| ディスク空き容量 | 200MB 以上（ログ・DBの増加分を含め余裕を持って） |

---

## 2-2. インストール手順

最新のリリースは GitHub の Releases ページからダウンロードします。

### 初回のみ：署名証明書のインストール

MSIX を実行する前に、一度だけ署名証明書をインストールします。

1. `UnionDuesCollectionManager_signing.cer` をダウンロードします
2. ファイルをダブルクリック →「証明書のインストール」をクリック
3. 「ローカルコンピューター」を選択 →「次へ」
4. 「証明書をすべて次のストアに配置する」を選択 →「参照」
5. **「信頼されたルート証明機関」** を選択 →「OK」→「次へ」→「完了」

### MSIX のインストール

1. GitHub Releases ページから `.msix` ファイルをダウンロードします
2. ダウンロードした `.msix` をダブルクリックして実行します
3. Windows App Installer が起動したら「インストール」をクリックします
4. スタートメニューまたはデスクトップのショートカットからアプリを起動します

---

## 2-3. 初回起動時に自動で行われる処理

アプリを初めて起動すると、以下が自動的に実行されます。操作は不要です。

### 暗号化キーの生成

- 場所：`%APPDATA%\AccountReconciler\secret.key`（アプリ専用の領域に振り替えられる場合があります。→ [第1章](01_overview.md)）
- 32バイトのランダムキー（AES-256用）が生成されます
- キーは Windows DPAPI でそのPC・ユーザーアカウントに紐付けて保護されます
- **このファイルを削除すると、登録済みの口座情報が復号できなくなります**

### データベースの作成

- 場所：アプリ専用フォルダの `SecureBank.db`（メンテナンス画面の「DBファイル情報」で確認できます）
- 必要なテーブルがすべて自動作成されます
- 既存のDBがある場合はマイグレーション（スキーマ更新）が自動適用されます

## 2-4. 初回セットアップ手順

初回起動後、以下の順番でセットアップを行います。

```
1. Kintoneドメインを設定（初回起動時の「Kintone接続設定」画面）
   ↓
2. ログイン確認
   ↓
3. Kintone接続設定（アプリIDの確認・APIトークンの取り込み）
   ↓
4. 質問機能の設定の取り込み（任意）
   ↓
5. 組織名・電話番号、全銀ファイルのコード区分の設定
   ↓
6. 自動更新用 GitHub PAT の設定（→ 2-5）
   ↓
7. 銀行マスタ・委託先口座・組合員口座の登録
   （→ 事務局と連携して実施）
```

### ステップ1：Kintoneドメインを設定

1. アプリを起動すると、ドメインが未設定の場合は **「Kintone接続設定」** 画面が表示されます
2. **「ドメイン」** 欄に組織のKintoneドメインを入力します
   - 例：`yourcompany.cybozu.com`（`https://` は不要）
   - `○○.cybozu.com`・`○○.cybozu-dev.com`・`○○.kintone.com` の形式が使えます
3. **「保存」** をクリックすると、ログイン画面に進みます

> ドメインをあとから変更する場合は、メンテナンス画面の **「Kintone設定」** で変更します。

### ステップ2：ログイン確認

1. ログイン画面でKintoneのログインIDとパスワードを入力します
2. ログインに成功し、ダッシュボードが表示されれば接続確認完了です

> ログインに必要なのはドメインだけです。APIトークンはログイン後にメンテナンス画面で取り込みます。

### ステップ3：Kintone接続設定

→ [第3章 Kintone接続設定](03_kintone_config.md) を参照してください。

### ステップ4：質問機能の設定（任意）

→ [第3章 3-4. 質問機能の設定](03_kintone_config.md#3-4-質問機能の設定) を参照してください。

### ステップ5：組織名・電話番号、全銀ファイルのコード区分の設定

帳票やグローバルヘッダに表示する組織名・電話番号と、全銀ファイルのコード区分を設定します。

1. 左側メニューから **「メンテナンス」** を開きます
2. **「組織名」** セクションで組織名と電話番号を入力し、**「設定を保存」** をクリックします
3. **「全銀ファイル」** セクションで、取引銀行の仕様書で指定されたコード区分（0：JIS／1：EBCDIC）を選び、**「設定を保存」** をクリックします

## 2-5. 自動更新の設定

アプリは起動時に新しいバージョンを自動で確認します。更新が検出されると、インストールを促すダイアログが表示されます。

### GitHub PAT の設定（初回のみ）

自動更新のダウンロードには GitHub Personal Access Token（PAT）が必要です。

**PAT の作成手順：**

1. GitHub にログインし、右上のアイコン →「Settings」→「Developer settings」→「Personal access tokens」→「Fine-grained tokens」を開きます
2. 「Generate new token」をクリックします
3. 設定：
   - **Repository access**：このリポジトリのみ
   - **Permissions** → **Contents**：`Read-only`
4. 「Generate token」をクリックし、表示されたトークンをコピーします

**PAT の設定手順：**

1. アプリの左側メニューから **「メンテナンス」** を開きます
2. **「アプリの更新」** セクションの **「GitHub PAT」** 欄に、コピーしたトークン（`github_pat_` から始まる文字列）を貼り付けます
3. **「設定を保存」** をクリックします
4. 「状態:」が **「設定済み」** になったことを確認します。設定は次回起動時から有効です

- PAT はこのPC・このWindowsユーザー専用に暗号化して保存されます
- 欄を空欄にして保存すると、PAT は削除されます（更新確認を行わなくなります）
- 以前の手順で作成した `update_config.json` が残っている場合は、アプリが読み込んで暗号化形式に移し、元のファイルを削除します

> PAT を設定しない場合、更新チェック自体がスキップされます（プライベートリポジトリのため認証が必要）。「状態:」には「未設定（更新確認を行いません）」と表示されます。

### 自動更新の動作

1. アプリ起動時にバックグラウンドで最新バージョンを確認します
2. 新しいバージョンが見つかると確認ダイアログが表示されます
3. 「今すぐ更新」→ MSIX がダウンロードされます
4. 「インストール」→ アプリが終了し、Windows App Installer が起動します
5. 「インストール」をクリックすると更新が完了します
6. アプリを再起動して新しいバージョンが適用されます

> アップデートでデータベースや設定が消えることはありません。ただし、アプリを**アンインストール**するとデータベース・暗号化キー・取り込んだ設定は削除されます（→ [第7章](07_backup_migration.md)）。

### DBマイグレーション（PC載せ替え後の注意）

PC を載せ替えた後（バックアップ→リストア済み）に旧バージョンのDBを復元した場合、起動時に自動でマイグレーションが適用されます。

- マイグレーションは起動時に自動実行されるため、手動操作は不要です
- マイグレーション失敗時はログ（データベースと同じフォルダの `logs`。→ [第8章](08_troubleshooting.md)）を確認してください
- 失敗する場合は担当開発者に連絡してください
